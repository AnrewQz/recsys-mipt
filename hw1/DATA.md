# Данные

Студент: Кузнецов Андрей.

Датасет: обезличенные данные маркетплейса из проекта «Кросс-доменная адаптация Marketplace → Wibes» Индустриального практикума.

Источник: выгрузка обезличенных взаимодействий пользователей маркетплейса и метаданных товаров, полученная для работы над проектом Индустриального практикума «Кросс-доменная адаптация Marketplace → Wibes».

В проекте рассматривается перенос предпочтений пользователей из маркетплейса в видеосервис Wibes. В домашней работе используем взаимодействия пользователей с товарами маркетплейса и метаданные товаров для персональных top-10 рекомендаций.

## Файлы и поля

`orders.parquet` содержит время взаимодействия `timestamp`, обезличенный ID пользователя `user_id` и ID товара `nm_id`.

`nm_meta.parquet` содержит ID товара `nm_id`, категорию `category_id` и подкатегорию `subcategory_id`.

Общее описание проекта предусматривает клики, добавления в корзину и покупки. В используемой выгрузке нет поля `event_type`, поэтому каждая строка трактуется как положительное взаимодействие без различения типов событий.

## Объём и подготовка

Исходный датасет этой работы уже очищен от пользователей с товарами без метаданных и содержит 66 077 477 взаимодействий, 466 443 пользователя и 11 010 265 товаров с взаимодействиями за период с 01.12.2024 по 30.11.2025. В справочнике метаданных — 11 320 117 товаров.

Выбираем 10 000 пользователей с `random_state=42`, оставляем товары с минимум двумя взаимодействиями и пользователей с минимум двумя оставшимися взаимодействиями.

Итоговая выборка: 9 128 пользователей, 724 070 взаимодействий и 218 832 товара с взаимодействиями. Справочник метаданных сохраняется полностью.
