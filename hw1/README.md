# Домашнее задание 1

Кузнецов Андрей.

Датасет: обезличенные данные маркетплейса из проекта Индустриального практикума «Кросс-доменная адаптация Marketplace → Wibes». [Описание и источник](DATA.md).

Результаты: [ноутбук](experiments.ipynb), [PDF](experiments.pdf).

Реализованы user-based kNN, iALS, EASE, FM с категориями и подкатегориями, iALS с таргетом на последних неделях. Параметры выбираются по NDCG@10 на validation. Финальное сравнение проводится по Recall@10 и NDCG@10 на test после переобучения на train + validation.

## Данные и запуск

Рабочий каталог — `hw1`. Рекомендуется Python 3.12.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Выгрузки получены при работе над проектом Индустриального практикума. Исходные для этой работы файлы `orders.parquet` и `nm_meta.parquet` нужно поместить в `hw1/data/`. `orders.parquet` уже очищен от пользователей с товарами без метаданных.

Откройте `experiments.ipynb` в Jupyter или VS Code, выберите созданное окружение как ядро и выполните ячейки по порядку. Сэмплирование, фильтрация, временной split 80/10/10, подбор и сравнение моделей выполняются в ноутбуке. Случайное зерно — 42.

Данные, окружения, кеши и генерируемые изображения исключены через `.gitignore`.
